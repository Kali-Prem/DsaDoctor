🪜 The Thinking Ladder & Waste Elimination Matrix

Brute force banane ke baad poochho: "Mera computer kahan waste (redundancy) kar raha hai?" Waste pakadte hi right data structure lagao:

Brute Force Me Kya Waste Ho Raha Hai? Sahi Tool / Technique Resulting Speedup
Linear search me baar-baar same element dhoonda ja raha hai 🗂️ HashMap / HashSet O(n²) ➔ O(n)
Subarray range [i..j] ka sum baar-baar recompute ho raha hai ➕ Prefix Sum Array O(n) query ➔ O(1)
Sorted array me pairs dhoondne ke liye nested loops hain ↔️ Two Pointers (Left / Right) O(n²) ➔ O(n)
Contiguous subarray me overlapping window check ho rahi hai 🪟 Sliding Window O(n²) ➔ O(n)
Search space sorted hai aur condition monotonic (T/F) hai 🎯 Binary Search on Answer O(n) ➔ O(log n)
Next greater / previous smaller element dhoondna hai 🥞 Monotonic Stack O(n²) ➔ O(n)
Stream me se Kth largest / smallest elements chahiye 🏔️ Min-Heap / Max-Heap O(n log n) ➔ O(n log k)
Same overlapping subproblems recursion me duplicate compute ho rahe hain 📊 Dynamic Programming (Memo / Tabulation) O(2ⁿ) ➔ O(n) ya O(n²)

Chapter 08

🆘 "Jab Atak Jao To Kya Karo" & Pre-Submit Checklist

Interview me dimag blank ho jaye ya edge case fail ho rahe hon, to is emergency protocol ko use karein:

01

🤯 Kuch Samajh Nahi Aa Raha?

Sabse chhota test case (2-3 elements) lo aur haath se pen-paper pe trace karo. Insaan jaise answer nikalta hai, wahi algorithm hai.

02

🔨 Brute Force Ban Gaya, Optimize Nahi Ho Raha?

Loop ke andar dekho: Kya repeat ho raha hai? Search repeat ho raha hai to Map lagao, range sum repeat ho raha hai to Prefix Sum.

03

⏱️ TLE (Time Limit Exceeded) Aa Raha Hai?

Complexity calculate karo. 10⁵ pe O(N²) TLE dega hi. Sorting + Binary Search ya Hashing lagakar O(N log N) ya O(N) me lao.

04

🐛 Corner Case Pe Code Fat Raha Hai?

Check karo: Empty array, single element, negative numbers, all duplicates, integer overflow (Integer.MAX_VALUE), 0 division.
